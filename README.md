# ⏰ ClockClock24 Simulation

This is a web-based simulation of **ClockClock24**, the kinetic clock art installation that uses 24 miniature analog clocks to form digital time through the coordinated movement of their hands.

Built using HTML, CSS, and JavaScript — no external libraries required.
